# Delegating to Grok

Full CLI reference: `agents/GROK_FOR_CLAUDE.md`. This skill is the Deadroll procedure.

## 1. Check it fits

Delegate only if all are true:
- the task touches **one folder or a few named files**;
- it does not change `crates/types`, `agents/CONTRACTS.md`, account layouts, CPI, signer checks, VRF, Session Keys or the hit order;
- the definition of done is checkable by a command (tests, `cargo run -p art`, `pnpm build`).
Otherwise do it yourself.

`grok --version` must work. On quota or login errors stop delegating and do the task yourself.

## 2. Write the brief to a file

`/tmp/grok-<task>.md`:

```
# Task <L3.5 wolf sprite>
Goal: <one paragraph>
Allowed to write: <exact paths or globs>
Read for context: <files>
Forbidden: everything else; docs/; crates/types; agents/; keys; .env; git commands that change history.
Rules:
- <paste root CLAUDE.md section 5 hard rules>
- Never use em dashes in generated text.
- <paste zone CLAUDE.md>
- <for sprites: paste pixel-sprite skill + one reference .dsl>
- <for UI: paste the exact TypeScript props interface>
Done when: <command> passes and <observable result>.
At the end list changed files and a 5-line summary.
```

## 3. Run in a box

Fresh session every time (no `-c`, no `-r`). Tight globs for the allowed paths:

```
grok --no-auto-update --no-alt-screen --cwd "$PWD" --always-approve --sandbox workspace \
  --effort medium --max-turns 30 --disable-web-search \
  --allow 'Read' --allow 'Grep' \
  --allow 'Write(<glob>)' --allow 'Edit(<glob>)' \
  --allow 'Bash(<test command>*)' \
  --deny 'Bash(rm *)' --deny 'Bash(git push*)' --deny 'Bash(git reset --hard*)' \
  --prompt-file /tmp/grok-<task>.md
```

For anything bigger than one folder use `--worktree` instead of globs.
Never run Grok on files another agent is editing.

## 4. Review before keeping

1. `git status --short`: only allowed paths changed. Anything else -> `git checkout -- <path>`, tighten globs, retry once.
2. `git diff`: read it. Check hard rules (no floats in crates, no secret lore, no em dashes, no keys).
3. Run the done command yourself.
4. Sprites: render the preview PNG and look at it.
5. Keep, fix by hand, or throw away. Commit under your lane with `Co-authored` note in the PR body: "partly generated by Grok, reviewed".

## 5. Parallel Grok runs

Several Grok runs at once are fine if their allowed paths do not overlap (e.g. `wolf.dsl`, `goblin.dsl`, `tiles.dsl` in three terminals). Review each separately.
