# @deadroll/sdk

TypeScript client for the Deadroll programs, generated by [Codama](https://github.com/codama-idl/codama) from the Anchor IDLs.

```ts
import { PROGRAMS, decodeEvents, errorName } from "@deadroll/sdk";
import { getActInstruction, fetchGameSession, SessionStatus } from "@deadroll/sdk/session";
```

Subpaths: `registry`, `render`, `character`, `items`, `map`, `session`, `city`.

Regenerate after `anchor build --tools-version v1.54`:

```
pnpm --filter @deadroll/sdk generate
pnpm --filter @deadroll/sdk check
```

Generate from a plain build, not after `pnpm deploy:local` (its `mock-vrf` session IDL has the mock VRF identity).

`check` fails when `idl/` differs from `target/idl` or `src/generated/` differs from a fresh render of `idl/`. The generated code is committed, so the website builds without Anchor.
