# Zone: sdk

Read the root CLAUDE.md first.

## What lives here
`@deadroll/sdk`: the TypeScript client of all 7 programs, generated by Codama from `idl/` (the only IDL copy in the repo). Used by `app/`, `tests/` and `tools/scripts/`.

- `idl/*.json`: copies of `target/idl`, refreshed by `pnpm generate`.
- `src/generated/<program>/`: Codama output (instructions, accounts, PDAs, errors, events, types) and `src/generated/errors.ts` (error names). Never edited by hand.
- `src/programs.ts`: `PROGRAMS` and the external program ids (mpl-core, session keys, VRF). The one place for addresses.
- `src/errors.ts`, `src/events.ts`: error names and Anchor event decoding from logs over the generated code.
- `scripts/generate.ts`, `scripts/check.ts`: generation and the freshness check.

## Rules for this zone
- After `anchor build` changes an IDL: `pnpm --filter @deadroll/sdk generate`, then commit `idl/` and `src/generated/` with the program change.
- Generate only from a plain build. `pnpm deploy:local` builds session with `mock-vrf`, whose IDL carries the mock VRF identity; until the next plain `anchor build -p deadroll_session`, `check` reports `idl/deadroll_session.json`.
- `@codama/renderers-js` is pinned to 2.5.0: newer versions emit code that needs `@solana/kit` 8.5. Bump it together with kit across the workspace.
- Consumers import `dist/` (built by `pnpm build`, gitignored). app, tests and scripts build it before they run.
- Hand-written code stays outside `src/generated/` and holds no layouts or discriminators of its own.

## Commands
```
pnpm --filter @deadroll/sdk generate   # target/idl -> idl/ -> src/generated
pnpm --filter @deadroll/sdk check      # fails if idl/ or src/generated is stale
pnpm --filter @deadroll/sdk build      # tsc -> dist/
pnpm --filter @deadroll/sdk test
```

## Done means
- `check`, `build` and `test` green
